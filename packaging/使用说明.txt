Codex 额度显示 1.0

安装：双击“Codex额度显示-安装.exe”，自动安装并启动，不需要管理员权限或另装 Python。
安装目录：%LOCALAPPDATA%\CodexQuotaWidget
支持：Windows 10/11 x64，已安装并登录的 Codex 桌面客户端。

登录 Windows 后后台启动；Codex 在前台时显示额度，切换到其他应用、最小化或关闭 Codex 时隐藏。
后台程序会继续等待 Codex 再次打开，不修改 Codex 客户端文件。
初次读取可能需要数秒。额度来自本机 Codex 登录状态；没有额度数据的账户会显示读取状态及错误提示。

右键额度文字：调整位置、固定、切换额度、刷新、退出。
双击额度文字：切换 5 小时额度和周额度。
不同窗口布局可能需要右键调整一次位置，再固定。
手动退出后，可以从开始菜单“Codex额度显示”重新启动，或下次登录 Windows 自动启动。

升级：再次运行安装包，会保留已有位置和额度窗口选择。
卸载：Windows 设置 → 应用 → 已安装的应用 → Codex 额度显示 → 卸载；或使用开始菜单中的卸载入口。
卸载会删除此工具和它的位置设置，保留 Codex 客户端及登录信息。
